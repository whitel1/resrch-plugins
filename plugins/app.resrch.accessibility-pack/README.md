# Resrch Accessibility Packs

Editor **accessibility theme packs** for Resrch, offered in
**Settings → Appearance** next to the bundled packs:

- **Colorblind Safe** — replaces the red/green diagnostic and highlight pair
  with blue/orange/yellow/purple so severity stays distinguishable under
  red-green color vision deficiency.
- **Low Stimulus** — softened selection, search-match, indent-guide, and
  diagnostic-border colors for light sensitivity, without removing the
  information they carry.

Theme packs override editor *roles* on top of any base and syntax theme, so
they compose with every UI theme in the product and with
`app.resrch.theme-pack`.
